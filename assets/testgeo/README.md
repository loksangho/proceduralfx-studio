# Test geometry

Spot, Bob and Blub are by Keenan Crane, from his model repository
(https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/). He released them into
the public domain (CC0 1.0): "As the sole author of this data, I hereby release it
into the public domain." The files here are the quad meshes and colour textures
from those archives, unchanged.

The Test Geometry node (Generators menu) builds them into the app.

The animated character (character.fbx, with its takes Idle, Walk, Run, Jump, Punch,
Death and Working, and the character_*.png colour palettes) is "Animated Human" by
Quaternius (https://quaternius.com, via
https://opengameart.org/content/animated-human-low-poly), released under CC0 1.0
Universal (public domain dedication), unchanged.
